# Proyecto Desarrollo Web

Proyecto realizado como práctica de desarrollo frontend durante mi formación en Coderhouse.

## Descripción

Sitio web multipágina desarrollado aplicando principios de maquetado web, organización de contenido y diseño visual mediante HTML y CSS.

El proyecto incluye distintas secciones navegables como:

* Inicio
* Menú
* Servicios
* Contacto
* Sobre nosotros

## Tecnologías utilizadas

* HTML5
* CSS3
* Git
* GitHub

## Estructura del proyecto

```text
ProyectoDesarrolloWeb/
│
├── proyecto/
│   ├── css/
│   ├── img/
│   ├── pages/
│   └── index.html
│
├── Wireframe/
├── pruebas/
└── README.md
```

## Objetivos del proyecto

* Crear una web estructurada en múltiples páginas.
* Aplicar buenas prácticas de maquetado HTML.
* Diseñar estilos personalizados con CSS.
* Organizar assets y archivos de manera clara.
* Versionar el proyecto con Git/GitHub.

## Lo aprendido

Durante este proyecto trabajé sobre:

* estructura semántica HTML
* navegación entre páginas
* diseño visual con CSS
* organización de carpetas
* manejo de recursos multimedia
* control de versiones con Git
